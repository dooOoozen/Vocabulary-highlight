使用教程

这个扩展能做什么

一边浏览英文网页，一边把生词“顺手”收进生词本。扩展会：

  • 双击取词：双击网页里的英文单词，自动高亮、还原词形（ate → eat）、查词典、发音并加入生词本；再次双击同一词即可移出。 选中网页上2～4 个英文单词组成的短语（如 pull up stakes、kung fu），松手后扩展会自动查本地词典。
  • 自动收藏例句（亮点）：双击单词加入生词本时，会顺手把该词所在的整句一并收藏为例句，方便结合语境记忆，无需手动整理。
  • 全文高亮：生词本和预设词书里的单词，在任意网页都会以主题色高亮，鼠标悬停即可发音并看释义。
  • 划句翻译：选中英文句子，点「译」或按快捷键（默认 Alt+T）即可就地翻译，还能收藏句子。
  • 背单词：按“不认识次数”加权抽词，忘记越多的单词出现越频繁；认识后按艾宾浩斯曲线安排复习。
  • 预设词书：一键导入中考 / 高考 / 四六级 / 考研 / 雅思 / 托福等开源词表，作为独立词书学习。
  • 自定义词典：导入你自己拥有的 MDX 词典，获得更专业的词典释义。

快速上手（三步）

  1. 在任意英文网页上双击一个不认识的单词，确认它已加入生词本并高亮，同时它所在的句子会自动收藏为例句。
  2. 点开扩展，进入背单词，选择词书后点击「开始背单词」。
  3. 看到单词先自己回忆，再点「显示答案」；认识点「认识」，不认识点「不认识」。

直接在下面这段英文上双击一个单词试试（此处仅演示高亮与翻译，不会加入生词本）：

Language learning opens a window to the world. Every unfamiliar word you meet is a small step forward, and reading every day quietly builds your vocabulary.

常用操作

  • 管理生词：在「生词本」搜索、展开看释义、删除或清空；左上角可切换词书。
  • 按来源学习：背单词时若选的是「生词本」，可按“全部 / 某日期 / 某来源”筛选后再背。
  • 两种背诵模式：全随机模式（现有模式）；补充模式（一次随机挑一批，认识一个自动补一个）。
  • 看进度：左侧栏底部有月历，背诵过的日期会变成主题色，点标题可展开全年日历。
  • 临时关高亮：网页右侧的小圆钮，点击可关闭当前网页的高亮，再点恢复。
  • 设置：配置翻译接口密钥、划句快捷键、主题色、词典导入与优先级等。

注意事项

  • 数据全部保存在本地 chrome.storage.local 与 IndexedDB，不上传；仅在你使用联网翻译/词典下载时访问对应服务。
  • 翻译接口需自行申请密钥（有道 / 百度 / 谷歌 / 彩云 / DeepSeek / Gemini / GPT）；本地词典命中时不调用接口，可省配额。
  • 预设词表与自定义 MDX 词典来自网络开源仓库或你自行获取，扩展只负责下载解析，不内置、不分发数据，请确保拥有合法使用权。
  • 网页高亮会跳过脚本、输入框、代码块等区域，避免破坏页面；在极高频刷新的页面上可能有少量性能开销。
  • 划句翻译默认快捷键为 Alt+T。

词典

扩展内置一份精简词典，可离线快速查询常见词；查不到的单词会回退到你所选的翻译接口。 你也可以从 GitHub 下载完整的 ECDICT 词典（约 66MB），解析出音标、英文释义、中文多义与词性后 缓存到本地，之后查询几乎零延迟。若下载失败，可到 https://github.com/skywind3000/ECDICT 手动下载 ecdict.csv 文件，再使用下方「本地载入」。

补充词典（合并）

若完整 ECDICT 仍有查不到的词（如 stiffen、shudder），可在此合并另一份 ECDICT 兼容的 CSV 词典（字段：word,phonetic,definition,translation,pos）， 按单词覆盖/新增，不会清空已下载的完整词典。可填写任意开源词库的原始 CSV 地址，或本地载入合并。

预设词书

一键导入中考、高考、四级、六级、考研、雅思、托福等开源词表，可随时添加或移除。 词表数据均来自网络开源仓库，本扩展仅提供下载与导入能力，不内置、不分发任何词表数据。

词典查询优先级

查词时按以下顺序依次查询，越靠前优先级越高。内置精简词典、完整 ECDICT 与自定义词典统一参与排序。

自定义词典（MDX，可多份）

可导入你自行获取的 MDict 词典文件（.mdx），如 LDOCE5++、OALD、COBUILD 等；可导入多份，优先级在左侧「词典查询优先级」中统一调整。 导入 .mdx 后，可在每份词典旁点击「导入 .mdd」加载配套资源包（CSS 样式 / 图片 / 音频），每份词典对应自己的 .mdd。 本扩展只提供解析与导入能力，不内置、不分发任何词典数据，请确保你拥有词典的合法使用权。 支持未加密、zlib 或未压缩的 MDict 2.0 格式；LZO 压缩或加密词典暂不支持。

数据导出

将本扩展的数据导出为 JSON 文件，便于备份或迁移。可选择导出范围，并自行选择保存位置。

数据存储与清理

本扩展的额外数据保存在浏览器扩展自身的存储中，不在扩展安装目录内：

  • chrome.storage.local：生词本、句子收藏、翻译接口配置。
  • IndexedDB（lv-dict）：完整词典（约 66MB）与查询缓存。

这些数据位于 Chrome 的用户数据目录（LevelDB / IndexedDB 文件）。可在地址栏输入 chrome://version 查看「个人资料路径」定位。卸载扩展后可能残留，可点击下方按钮一键清理。

词书生成
